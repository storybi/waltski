Bond Yields Are Rising Everywhere—Except China

Claude Marketplace

Pair Claude with BlackLine from the Claude Marketplace for reconciliations

BlackLine and its Verity AI agents are now on Anthropic’s Claude Marketplace, and companies with an Anthropic spend commitment can apply part of it to BlackLine. Claude handles the reasoning and write-ups while BlackLine supplies the accounting logic and SOX-ready control console, so reconciliation work stays auditable.

Models

Route high-volume variance commentary to Sonnet 5.5

Sonnet 5.5 costs $2 per million input tokens and $10 per million output, half of Opus 5.5, and scores about the same on real-work benchmarks like GDPval. Use it for the bulk of first-draft account commentary and save Opus for the tricky judgment calls.

Try“Write one-paragraph variance explanations for every cost center over 5% off budget in this file, plain English, leading with the dollar impact and the driver.”
Fello AI · Nov 18, 2026
Claude Code

Try Code Mode to batch the data pulls behind a reporting pack

Claude Code’s new experimental Code Mode lets Claude write a short JavaScript step that chains several tool calls at once, instead of one call per turn. For a BI or FP&A analyst, that means pulling, joining and checking several data extracts in one pass; it is opt-in and terminal-only for now.

Try“Pull last month’s sales, returns and freight extracts, join them by branch, check that totals tie to the GL, and save a summary CSV with any branch that doesn’t tie.”
MarkTechPost · Nov 17, 2026

Use read-only bank links as the model for finance data access

Anthropic’s Personal Finance beta connects bank and card accounts through Plaid in read-only mode, so Claude can analyze but never move money. It is a good template for company policy too: give Claude read-only connections to ERP and bank data, and keep approvals and payments with people.
